# Pure HTML Table Ludo Board
A creative Ludo board built using pure HTML and HTML table elements.
## About the Project
This project demonstrates how HTML table elements can be used to create a structured Ludo board without using CSS or JavaScript.
## Features
• Created using pure HTML
• Built with HTML table elements
• Structured Ludo board layout
## Technologies Used
• HTML5
